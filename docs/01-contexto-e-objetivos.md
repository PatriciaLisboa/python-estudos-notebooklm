# Contexto e Objetivos

## Contexto

Este projeto foi desenvolvido com o objetivo de utilizar a Inteligência Artificial como ferramenta de aprendizagem ativa para estudar os fundamentos da linguagem Python.

O NotebookLM será utilizado como ambiente de apoio aos estudos, permitindo trabalhar com fontes selecionadas, elaborar perguntas, comparar informações, revisar conceitos e apoiar a prática de programação.

## Objetivo geral

Aprender os fundamentos da linguagem Python por meio de uma abordagem de aprendizagem ativa, utilizando Inteligência Artificial como ferramenta de apoio ao processo de estudo.

## Objetivos específicos

- Compreender a sintaxe básica de Python;
- Aprender os principais tipos de dados;
- Trabalhar com estruturas de dados;
- Utilizar estruturas condicionais e de repetição;
- Criar e utilizar funções;
- Compreender tratamento de exceções;
- Conhecer módulos e recursos da biblioteca padrão;
- Desenvolver pequenos programas em Python;
- Utilizar Inteligência Artificial de forma crítica durante o processo de aprendizagem;
- Documentar as dificuldades, descobertas e estratégias utilizadas durante os estudos.
