# 🐍 Python — Estudos com NotebookLM

Projeto de aprendizagem ativa de Python utilizando Inteligência Artificial, NotebookLM, curadoria de fontes e engenharia de prompts.

## 🎯 Objetivos

O projeto tem como objetivo estudar os fundamentos da linguagem Python utilizando a Inteligência Artificial como ferramenta de apoio à aprendizagem ativa.

Durante o projeto serão explorados:

- fundamentos da linguagem Python;
- prática de programação;
- curadoria de fontes;
- engenharia de prompts;
- análise crítica das respostas da IA;
- resolução de problemas;
- documentação do processo de aprendizagem.

## 🤖 Inteligência Artificial como ferramenta de aprendizagem

O NotebookLM será utilizado não apenas para obter respostas, mas como ferramenta de apoio ao processo de aprendizagem.

A metodologia envolve:

1. pesquisar e selecionar fontes;
2. formular perguntas;
3. analisar as respostas da IA;
4. testar o conhecimento;
5. praticar programação;
6. identificar erros e dificuldades;
7. revisar os conceitos;
8. documentar os aprendizados.
